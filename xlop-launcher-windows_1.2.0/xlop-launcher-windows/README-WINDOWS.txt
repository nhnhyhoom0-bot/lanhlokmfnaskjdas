xlop launcher 1.2.0 - Windows
==============================

التشغيل (مرة واحدة تثبيت Python، بعدها نقرتان):
  1) ثبّت Python 3.8 أو أحدث من https://www.python.org/downloads/windows/
     (النسخة الرسمية تأتي مع Tkinter تلقائيًا).
  2) انقر مرتين على  xlop-launcher.exe
     - يظهر مربع أسود لثانية ثم يختفي: هذا طبيعي.
     - إن لم يفتح شيء: انقر مرتين على الملف  xlop-launcher-script.pyw  مباشرة.

أين تُحفظ بياناتي؟
  اللانشر وحساباتك:  %APPDATA%\xlop-launcher
  اللعبة:            %APPDATA%\.minecraft
  سجل الأخطاء:       %APPDATA%\xlop-launcher\launcher.log

الحسابات: أوفلاين و Ely.by يعملان مباشرة. حساب Microsoft يحتاج معرّف تطبيق معتمد من Mojang
  يضعه الناشر في الملف  microsoft_client_id.txt  (انظر README-BUILD.md).
التحديثات: يضع الناشر رابط latest.json في  update_url.txt .

نسخة مستقلة لا تحتاج Python:  استخدم حزمة المصدر (xlop-launcher-windows-source.zip) وملف README-BUILD.md.

English: install Python 3.8+ from python.org, then double-click xlop-launcher.exe
(or xlop-launcher-script.pyw). A standalone exe (no Python) is built from the source package.
